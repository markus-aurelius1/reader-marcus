## Ancient & Classical {#ancient-classical}

| Tradition | Forms | Character | Significance |
|---|---|---|---|
| **Vedic Sanskrit** | Vedas → Brahmanas → Aranyakas → Upanishads | Oral, mnemonic | Religion, society; ritual → metaphysics |
| **Epic–Puranic** | Ramayana, Mahabharata, Gita, Puranas | Narrative, didactic, layered | Dharma, kingship; pan-Indian motifs |
| **Classical Sanskrit** | Kavya, nataka, grammar, science | Formal aesthetics; rasa / alankara | Court culture + secular knowledge |
| **Pali–Buddhist** | Tipitaka, Dhammapada, Jatakas | Dialogue, parable | Ethics; monastic pedagogy; trans-Asian reach |
| **Prakrit / Jain** | Agamas, Gatha Saptashati | Vernacular, didactic | Wider audiences; bridge to regional languages |
| **Tamil / Sangam** | Ettuthokai, Pattuppattu, Tolkappiyam | Akam–Puram, ecology, realism | Distinct southern world |

- Never only religious → Panini, Kalidasa, *Panchatantra*, *Arthashastra*, *Charaka* and *Sushruta Samhita*.
- Argument → ==continuity without uniformity== — sacred / secular, elite / vernacular, oral / written, Sanskritic / non-Sanskritic interacted.

## Sangam as Social Archive {#sangam}

- **Akam** → inner world: love, separation. **Puram** → public world: war, kingship, generosity.
- **Tinai** → ecology fused with livelihood and mood.

| Tinai | Landscape | Livelihood |
|---|---|---|
| **Kurinji** | {{Hills}} | Hunting |
| **Mullai** | {{Pastoral}} | Herding |
| **Marutham** | {{Farmland}} | Agriculture |
| **Neital** | {{Coast}} | Fishing, pearl-diving |
| **Palai** | {{Arid}} | — |

| Reveals | Evidence |
|---|---|
| **Maritime economy** | Yavanas; pearls, spices, textiles; ports {{Puhar, Musiri, Korkai}}; Roman coins |
| **Craft economy** | Textiles, metallurgy, salt, shipbuilding; towns |
| **Social differentiation** | Rulers, priests, landholders, merchants; performers, artisans |
| **Gender** | Courtship themes; women poets — {{Avvaiyar}} |
| **Cultural life** | Music, festivals, gift-giving, heroic ethos |

- Evaluation (2013) → vivid for society and economy; weak for continuous political chronology — convention, uncertain dating, exaggeration, patron's view.
- Thesis → "less a dynastic chronicle than an ethnography in verse".

## Persian & Vernacular Worlds {#persian-vernacular}

| Persian genre | Works | Shows |
|---|---|---|
| **Chronicle** | *Tabaqat-i-Nasiri*; Barani's *Tarikh-i-Firoz Shahi*; Abul Fazl's *Akbarnama / Ain-i-Akbari* | Polity, revenue, hierarchy |
| **Memoir** | *Baburnama*, *Tuzuk-i-Jahangiri*, *Humayun Nama* | Court culture, elite life |
| **Poetry / Sufi** | Amir Khusrau; malfuzat — {{Fawaid-ul-Fu'ad}} | Mysticism, Indo-Persian synthesis |
| **Translation** | Razmnama; Dara Shikoh's Sirr-i-Akbar | Knowledge exchange |

**"Spirit of the age" (2020)** → state-building: chronicles · hierarchical court: etiquette, offices · agrarian economy: revenue, measurement, prices · composite culture: Indian idioms in Persian · Sufi ethos · translation = encounter, not isolation.
- Qualifier → elite-centred, patron-dependent, panegyric → corroborate with regional literature, inscriptions, travellers.

> [!FLOW] Court / temple / monastery patronage + Bhakti + regional states + oral tradition → more literary languages → stronger regional identities

- Tamil: Alvar–Nayanar · Kannada: *Kavirajamarga*, vachanas · Telugu: Vijayanagara court · Marathi: Jnaneshwar, abhang · Awadhi / Braj: Tulsidas, Surdas, Kabir · Bengali / Assamese: Chaitanya milieu, Sankardeva's Borgeet.
- Persianisation and vernacularisation → ==parallel, interacting== — not "foreign vs indigenous".
- Sheldon Pollock → Sanskrit cosmopolis → vernacularisation.

**Krishnadeva Raya (2016)**
- Reign {{1509–29}}; author of {{Amuktamalyada}} (Telugu).
- Patronage across Telugu, Kannada, Tamil, Sanskrit.
- Ashtadiggajas → Allasani Peddana (*Manucharitamu*), Nandi Thimmana (*Parijathapaharanamu*).

> [!FLOW] Political power → patronage → scholarly congregation → prestige of language → canon formation

Works and authors → [Persian Chronicles](@prelims/history-culture/literature-travellers#persian-chronicles) · [Rulers — PYQ Anchors](@prelims/history-culture/vijayanagara#rulers)

## Modern Literature {#modern}

> [!FLOW] Print + modern education + public sphere + colonial encounter + reform + nationalism → new genre, audience and subject

- **Print** → newspapers, journals, pamphlets → multilingual public sphere.
- **Prose / novel** → Bankim's {{Anandamath (1882)}} → historical fiction + nationalist imagination.
- **Social archive** → regional novels on rural life, caste, class.
- **Mobilisation** → Tagore's songs; Subramania Bharati's *Sudesha Geetham* in Swadeshi.
- **Postcolonial realism** → Basheer, Thakazhi, G.V. Krishna Rao → ordinary and marginal lives.
- **Vande Mataram** → Bangadarshan → Anandamath → political symbol: literature makes shared vocabulary.
- Later democratisation of voice → progressive, Dalit, feminist, Indian-English writing.

| Before | After |
|---|---|
| Court / sect audience | Print public |
| Verse dominant | Prose, novel, journalism |
| Patronage | Market, publication networks |
| Cultural description | Reform + nationalism + social critique |

Public sphere and reform → [Socio-Religious Reform](@socio-religious-reform#awakening-nation)

## Centres of Learning {#centres-of-learning}

| | Taxila | Nalanda |
|---|---|---|
| **Character** | Network of teachers / schools | Institutional monastic-scholastic complex |
| **Organisation** | {{Decentralised}}, teacher-centred | Residential, integrated |
| **Pedagogy** | Guru–shishya | Scholarly community, debate |
| **Curriculum** | Philosophy, medicine, mathematics, astronomy, statecraft | Buddhist studies + logic, grammar, secular subjects |
| **Draw** | Crossroads to Persia / Central Asia | International Buddhist centre |
| **"University"?** | Weak — no central curriculum or degree authority | Closer, still premodern |

- Network → Nalanda · Vallabhi · Vikramashila · Odantapuri · Taxila = nodes, not isolated campuses.
- Xuanzang recorded Nalanda and Vallabhi; {{Atisha Dipankara}} carried learning from Vikramashila to Tibet.

> [!FLOW] Patronage + trade / pilgrimage routes + residential learning + manuscripts + travelling monks / translators → trans-Asian knowledge circulation

- Line → a ==mobile intellectual ecology== of courts, monasteries, teachers, merchants and routes.

> [!TRAP] Do !!not!! apply the modern "university" category mechanically (2014 Taxila question turns on this).
