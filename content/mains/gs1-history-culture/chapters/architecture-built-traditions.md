## Harappan Urbanism {#harappan}

- Core proposition → distinctive for ==planned urban systems==, not royal monumentality.

| Dimension | Points |
|---|---|
| **Morphology** | Grid streets; main streets → lanes (traffic + privacy); citadel / lower town; Dholavira's segmented plan |
| **Standardisation** | Brick ratio {{4:2:1}}; shared norms over a huge area |
| **Regional variation** | Baked brick (Harappa, Mohenjo-daro); mud brick (Kalibangan); stone (Dholavira) |
| **Civic infrastructure** | Covered drains linking houses to street drains; inspection access; wells; bathing areas |
| **Hydraulics** | Great Bath — waterproof brick / gypsum; Dholavira reservoirs and storm-water channels |
| **Domestic** | Courtyard houses; few openings on main streets; some multi-storey |
| **Economic** | Granary-type stores; craft quarters; Lothal basin read as dockyard; fortification = defence / flood control / demarcation |

**Built form → inference**
- Drainage → collective civic coordination.
- Standardisation → shared metrology.
- Courtyard, private bath → privacy, domestic order.
- Water works → ecological adaptation.
- No securely identified giant palace / tomb (vs Egypt, Mesopotamia) → different expression of authority.

**Relevance today (2014)** → integrated drainage · zoning · standardisation · water harvesting · local materials · compact neighbourhoods · hygiene.
- Lesson → infrastructure before / with settlement, not retrofitted.

> [!TRAP] Similarity with modern cities is !!functional, analogical!! — not direct institutional continuity. Scale, transport, land markets and governance differ.

- Wheeler, Piggott → stressed uniformity; balance with Dholavira / Lothal / Kalibangan variation.

Site facts → [Town Planning & Technology](@prelims/history-culture/prehistory-harappan#town-planning-technology)

## Rock-Cut & Buddhist Architecture {#rock-cut}

| Form | Function | Identifiers |
|---|---|---|
| **Stupa** | Relic veneration | Anda, harmika, yashti-chhatra, vedika, torana, pradakshina patha |
| **Chaitya-griha** | Congregational worship | Apsidal hall, nave + aisles, vaulted roof, chaitya window |
| **Vihara** | Residence, learning | Cells round a hall; later a shrine |

> [!FLOW] Barabar (Mauryan) → Bhaja–Karle–Nashik (Western Deccan) → Ajanta → Udayagiri / Badami / Elephanta (Hindu) → Ellora (Buddhist + Hindu + Jain; Kailasa)

- **Barabar–Nagarjuni** → 3rd c. BCE; {{Ajivika}} link; {{Lomas Rishi}} façade copies timber in stone.
- **Western Deccan** → tied to merchants and Western Ghat routes.
- **Ellora Kailasa** → structural-temple design excavated as a monolith.

**Why technologically important**
- ==Subtractive architecture== → made by removing rock; errors cannot be rebuilt.
- Needs advance volumetric planning.
- Stone translation of perishable wooden prototypes.

**As a historical source (2020)**

| Reveals | Evidence |
|---|---|
| **Religion** | Aniconic → iconic Buddhism; Hindu / Jain coexistence (Ellora) |
| **Economy** | Merchant / guild donor inscriptions at Karle, Nashik; trade-route siting |
| **Polity** | Patronage as legitimacy — Mauryas, Satavahana-linked donors, Vakatakas, Chalukyas, Rashtrakutas |
| **Technology** | Quarrying, polishing, structural simulation |
| **Society** | Dress, jewellery, music, gender in paintings and reliefs |
| **Language** | Brahmi / Prakrit inscriptions |
| **Institution** | Vihara as residential, ritual, educational space |

- Limits → religious / elite patronage · survival bias for stone · inscriptions name donors, not everyone · later additions blur chronology.
- Line → valuable archive ≠ complete mirror of society.

Vocabulary → [Rock-Cut Architecture](@prelims/history-culture/architecture-sculpture#rock-cut)

## Temple Architecture {#temple}

> [!FLOW] Garbhagriha → antarala → mandapa(s) → tower (shikhara / vimana) → pradakshina axis → programmed sculpture

| Marker | Nagara | Dravida | Deccan / "Vesara" |
|---|---|---|---|
| **Region** | North, central, east | Peninsula, Tamil region | Deccan |
| **Tower** | Curvilinear {{shikhara}} | Pyramidal tiered {{vimana}} | Hybrid |
| **Summit** | Amalaka + kalasha | Stupika | Variable |
| **Gateway** | Subordinate | Monumental gopuram (later) | Variable |
| **Examples** | Deogarh, Khajuraho, Lingaraja, Konark | Shore Temple, Brihadisvara | Pattadakal, Hoysala |

- Adam Hardy → Nagara and Dravida as two classical "languages"; monuments recombine the grammar.
- Categories are analytical, not watertight → Pattadakal has both idioms.

**Evolution chain**
- **Pallava** → cave mandapa (Mahendravarman) → monolithic ratha (Mamalla; Pancha Rathas) → structural temple (Rajasimha; Shore, Kailasanatha). A laboratory for Dravida.
- **Chalukya** → Aihole (experiment) · Badami (cave) · Pattadakal (both idioms).
- **Rashtrakuta** → Kailasa, Ellora.
- **Hoysala** → star plan, lathe-turned pillars, dense soapstone ornament (Belur, Halebid, Somanathapura).

**Chola "high watermark" (2013, 2024)** → scale + engineering + integration + institution + symbolism.
- Brihadisvara, Thanjavur → axial plan, dominant vimana.
- Gangaikondacholapuram → refinement. Airavatesvara, Darasuram → intricacy.
- Temple = ritual centre + political statement + employer + landholder + inscription archive + arts centre.
- Bhakti + bronze processions + architecture = sacred-cultural ecosystem.

**Regional Nagara**
- **Odisha** → rekha-deul + pidha-deul; Lingaraja → Jagannath → Konark.
- **Chandella** → clustered shikharas on a high platform; sculptural skin.
- **Solanki** → ornate toranas, pillared halls; Modhera.
- Bengal brick / Himalayan wood → material ecology shapes style.

**Vijayanagara amalgamation (2026)**

| Layer | Evidence |
|---|---|
| **Inherited** | Dravida plan; Chola / Pandya / Hoysala sculptural and pillared traditions |
| **Innovated** | {{Raya gopurams}}; kalyana mandapas; composite pillars; temple–bazaar axes; hydraulic, fortified city |
| **Contemporary synthesis** | Arches, vaults, domes in courtly buildings — {{Lotus Mahal, Elephant Stables}} |
| **Anchors** | Vittala (stone chariot, pillared hall); Hazara Rama (narrative reliefs) |

**Architecture as philosophy (2020)** → sacred centre: garbhagriha · cosmic mountain: shikhara · circumambulation: ritual movement · relic: stupa · narrative relief: doctrine made visual. Show how ideas became design choices.

Style facts → [Temple Styles](@prelims/history-culture/architecture-sculpture#temple-styles) · [Hampi](@prelims/history-culture/vijayanagara#hampi)

## Indo-Islamic & Deccan {#indo-islamic}

- Thesis → new structural concepts + Indian materials and craftsmen + regional traditions + political patronage → hybrid form.

| Incoming / strengthened | Indian continuities |
|---|---|
| True arch, dome, vault, minar | Trabeate post-and-lintel; corbelling |
| Large congregational space; geometric plan | Brackets, chhatris; lotus / bell motifs |
| Calligraphy, arabesque, jali, charbagh, pietra dura | Rich stone carving |

- Early phase → structural negotiation before technical synthesis.

| Phase | Markers |
|---|---|
| **Early Sultanate** | Qutb complex; arcuate system develops |
| **Tughlaq** | Battered walls, fortress mass, austerity |
| **Provincial** | Bengal brick / terracotta, curved roof; Gujarat carving, jalis; Jaunpur, Malwa |
| **Humayun's Tomb** | Garden-tomb, charbagh |
| **Akbar** | Red sandstone; trabeate + arcuate; Fatehpur Sikri |
| **Shah Jahan** | White marble, symmetry, double dome, pietra dura — Taj, Red Fort, Jama Masjid |
| **Deccan** | Bahmani (Gulbarga, Bidar; Mahmud Gawan Madrasa) · Bijapur ({{Gol Gumbaz}}, Ibrahim Rauza) · Qutb Shahi (Charminar) |

- Deccan argument → regionalisation within a Persianate world, not one "Islamic style".

Features → [Indo-Islamic Features](@prelims/history-culture/architecture-sculpture#indo-islamic)

## Colonial & Modern {#colonial-modern}

| Phase | Markers | Meaning |
|---|---|---|
| **Portuguese / French** | Goa churches, coastal forts; Pondicherry grid | Commerce + naval power |
| **Neo-Classical** | Columns, pediments, symmetry | Rational, orderly empire |
| **Victorian Gothic** | Pointed arches, towers; CSMT Mumbai | Railway-era institutions + Indian craft |
| **Indo-Saracenic** | Domes, chhatris, jalis + European planning; Gateway of India, Madras High Court | Empire as ==successor of Indian kingship== |
| **Lutyens–Baker New Delhi** | Axes, vistas, zoning; Rashtrapati Bhavan's "Delhi Order" | Political hierarchy made spatial |
| **Chandigarh / Le Corbusier** | Capitol Complex; concrete, brise-soleil | Nation-building, modernity |
| **Correa · Laurie Baker** | Climate, culture, low-cost local materials | Contextual regionalism |

> [!FLOW] Imperial authority → developmental nation-building + functionalism + modern technology + search for Indian identity

- Thesis → colonial form legitimised an external empire; postcolonial form articulates development, democracy and identity.
- Contemporary ending → conservation duty under `Article 49` and `Article 51A(f)`.
