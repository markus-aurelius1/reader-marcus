## What & Why {#what-why}

| Heritage | Components | Conservation logic |
|---|---|---|
| **Tangible — immovable** | Monuments, sites, historic cities, landscapes | Fabric + setting + stability + compatible use |
| **Tangible — movable** | Sculptures, coins, paintings, manuscripts | Provenance + inventory + storage + anti-trafficking |
| **Intangible / living** | Oral traditions, performance, ritual, craft | Viability + transmission + community agency |

- Distinction → tangible: conserve fabric + values. Intangible: conserve the ==conditions of transmission==, not a frozen form.

**Why safeguard**
- Civilisational memory.
- Identity + social cohesion — unity in diversity.
- Historical evidence → loss is irreversible.
- Intergenerational equity → finite, non-renewable resource.
- Livelihoods → craftspeople, performers, guides.
- Cultural tourism — within carrying capacity.
- Soft power → heritage, yoga, Buddhism, crafts.
- Creative continuity → motifs feed contemporary design.

## Threat Matrix {#threats}

| Threat | Mechanism | Example |
|---|---|---|
| **Physical decay** | Weathering, moisture, vegetation | Murals, stone surfaces |
| **Pollution** | Chemical weathering | Taj Mahal |
| **Climate / disaster** | Flood, earthquake, extreme rain | Kedarnath, 2013 |
| **Urbanisation, encroachment** | Skyline, vibration, construction | Monument precincts |
| **Infrastructure conflict** | Roads, bridges cut integrity | Hampi bridge |
| **Overtourism** | Abrasion, waste, microclimate | Cave / temple complexes |
| **Poor restoration** | Cement, conjectural rebuilding | Loss of authenticity |
| **Theft, trafficking** | Weak inventories, provenance | Temple idols |
| **Governance fragmentation** | Centre–State–ULB–trust overlaps | Inconsistent management |
| **Transmission failure** | Ageing practitioners, migration | Puppetry, crafts |
| **Commercialisation, mechanisation** | Form simplified; machines undercut artisans | Handloom decline |

## Conservation Principles {#principles}

| Principle | Meaning |
|---|---|
| **Value-based** | First establish why it matters, then decide intervention |
| **Authenticity** | Values credibly expressed through form, material, use, technique, setting, spirit |
| **Integrity** | Wholeness, intactness of attributes |
| **Minimum intervention** | Repair only what is needed; compatible materials; traditional craft |
| **Preventive > restorative** | Drainage, vegetation control, monitoring, visitor management |
| **Documentation first** | Record before any intervention |
| **No conjectural reconstruction** | Only exceptionally, on complete documentation |
| **Setting matters** | Skyline, approach, visual corridors are part of the value |

> [!FLOW] Inventory → unique ID / provenance → measured record → condition / risk map → intervention → monitoring → public archive

- Documentation uses → baseline · guides restoration and disaster recovery · identifies stolen objects · enters master plans · digital access with less footfall.
- Intangible → archive cannot replace guru–shishya, performance opportunity, livelihood support.
- **Nara Document (1994)** → authenticity is culturally contextual, not original masonry alone.
- **2003 ICH logic** → keep the capacity to evolve; freezing a "pure original" destroys living heritage.

| Old doctrine | Current doctrine |
|---|---|
| Monument-centric, expert-controlled, repair after decay | Values-based, preventive, landscape, living heritage, community stewardship |

## Community & Development Trade-offs {#community-development}

- Living heritage → communities are ==bearers and transmitters==, not beneficiaries; free, prior, informed consent.
- Mechanisms → community inventories · site committees · hereditary artisan representation · apprenticeships · revenue-sharing · community guides · participatory impact assessment · co-management with trusts and municipalities.

| Tension | Balanced principle |
|---|---|
| **Infrastructure vs setting** | Heritage Impact Assessment + alternatives |
| **Tourism vs carrying capacity** | Timed entry, visitor caps, revenue for conservation |
| **Restoration vs authenticity** | Minimal intervention; no "beautification" |
| **Modern use vs preservation** | Adaptive reuse |
| **Living worship vs museumisation** | Keep ritual, manage load |
| **Livelihood vs exclusion** | Co-management, not displacement |
| **Access vs fragile fabric** | Reversible measures + digital alternatives |

- **Hampi** → intrusive bridge → World Heritage in Danger list → integrated planning, traffic control → removed in {{2006}}. Lesson: development must be compatible, planned, site-sensitive.

## Way Forward {#way-forward}

> [!FLOW] Reactive monument repair → preventive + landscape + community + livelihood stewardship

1. Complete inventories and provenance; interoperable IDs.
2. Preventive conservation — condition audits, monitoring.
3. Digital documentation — GIS, photogrammetry, 3-D scans.
4. Heritage bye-laws and impact assessment inside city master plans.
5. Professional capacity — conservation architects, material scientists, traditional masons.
6. Anti-trafficking chain — inventory → police / customs → restitution.
7. Community co-management and revenue-sharing.
8. ICH livelihood ecosystem — apprenticeships, GI, market access.
9. Tourism carrying capacity.
10. Climate / disaster risk maps and salvage protocols.
11. Partnerships with safeguards — core decisions stay professional.
12. Measure condition, authenticity, transmission — not just spend or footfall.
