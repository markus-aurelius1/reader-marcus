## Critical Minerals & Battery Metals {#critical-minerals}

| Mineral | Geography | Hook |
|---|---|---|
| **Cobalt** | {{DR Congo}} dominates mining | Battery cathode |
| **Nickel** | {{Indonesia}} dominates mining | Battery + stainless steel |
| **Lithium** | **Lithium Triangle** = {{Argentina, Bolivia, Chile}} (brine resources); Australia leads mine output | Triangle = resources, not the production ranking |
| **Rare earths** | {{China}} dominates mining and processing | {{17}} elements = 15 lanthanides + scandium + yttrium |
| **Copper** | {{Chile}} — porphyry deposits, northern Andes | |
| **Iodine** | {{Chile}}; then Japan | |
| **Graphite** | China | Battery {{anode}} |

- Lithium-ion battery → **cathode** uses lithium + nickel + cobalt (varies; LFP uses none of the last two). **Anode** → graphite.
- Rare earths → magnets, displays, phosphors, lasers. "Rare" ≠ found in only a few countries.

> [!TRAP] Mine production ≠ reserves ≠ refining. Read which one the question asks.

> [!DYN] Producer shares and ranks (latest: 2025 output — DR Congo ~73% of cobalt, Indonesia ~67% of nickel, China ~69% of rare earths; lithium Australia > China > Chile) shift every year — recheck before the exam.
