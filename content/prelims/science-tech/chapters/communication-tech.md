## Wireless — Comparison {#wireless}

| Technology | Uses | Range | Key point |
|---|---|---|---|
| **Bluetooth** | Radio, {{2.4 GHz}} | Short — device to device | No line of sight needed |
| **Wi-Fi** | Radio, 2.4 and 5 GHz | Local network (WLAN) | |
| **NFC** | Radio field | {{A few centimetres}} | Tap to pay; can be encrypted |
| **RFID** | Radio tag + reader | Short | Tracking, toll tags |
| **LiFi / VLC** | {{Visible light}} (LED) | Short | No radio interference; cannot pass walls |

- NFC does !!not!! work at a metre.
- **Visible Light Communication** → 375–780 nm; faster than Bluetooth.
- CCTV, RFID and WLAN → all short-range.

How light and radio fit the spectrum → [EM spectrum](@physics-everyday#em-spectrum)

## Mobile Generations, LTE & 5G {#mobile}

> [!FLOW] 2G voice → 3G mobile data → 4G / LTE fast internet → 5G very low delay, huge device numbers.

- **LTE** → marketed as {{4G}}.
- **VoLTE** → voice calls carried over the LTE data network; data keeps running during a call.
- **5G** → low, mid and high bands; network slicing; small cells; edge computing.

> [!TRAP] LTE is !!not!! 3G, and VoLTE is !!not!! "voice only" or "advanced 3G".

Satellites for communication → [Orbits](@space-technology#orbits)

## VPN {#vpn}

- **Virtual Private Network** → encrypted tunnel through the public internet into a {{private network}}.
- A security path — not cloud software.

> [!DYN] Exact speeds, ranges and frequency bands of Wi-Fi, 5G and RFID change with each standard — not for memorising.
