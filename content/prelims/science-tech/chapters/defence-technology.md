## Missiles {#missiles}

| | Ballistic missile | Cruise missile |
|---|---|---|
| Power | Rocket at launch, then {{falls along an arc}} | {{Powered by an engine all the way}} |
| Path | High arc; long-range ones leave the atmosphere | Low, inside the atmosphere; hugs terrain |
| Example | **Agni** | **BrahMos**, Tomahawk |

- **BrahMos** → {{India–Russia}}; supersonic cruise missile.
- **Agni-IV** → surface-to-surface ballistic missile; solid fuel.
- **Anti-radiation missile** → homes on enemy {{radar}} signals → RudraM (air-to-surface).
- **Hypersonic** → Mach 5 or more. Glide vehicle (boosted by rocket, then glides) or scramjet cruise missile.
- **MIRV** → one missile, {{several warheads}}, each for a different target.
- **FOBS** (Fractional Orbital Bombardment System) → warhead put into low orbit, brought down on target before completing one orbit → attack from an unexpected direction.

Missile export-control regimes → [International Relations](@prelims/international-relations)

> [!TRAP] "Ballistic missiles are jet-propelled throughout" and "cruise missiles are rocket-powered only at launch" are both reversed.

## Air & Missile Defence {#air-defence}

- Chain → detect → track → decide → intercept.
- Layers of radars, command centres and interceptors — not one missile.

| System | Country | Against |
|---|---|---|
| **THAAD** | {{USA}} | Ballistic missiles, high altitude |
| **Iron Dome** | {{Israel}} | Short-range rockets |
| **S-400** | Russia | Aircraft, missiles — long range |

## Drones {#drones}

| Type | Can it hover? |
|---|---|
| **Multi-rotor** | Yes; takes off vertically; short endurance |
| **Fixed-wing** | {{No}}; long range; needs runway or catapult |
| **Hybrid VTOL** | Vertical take-off + efficient forward flight |

- Power → batteries, fuel engines, hybrids, fuel cells — not batteries alone.
- **Loitering munition** → circles, then dives on the target ("kamikaze drone").
- **Drone swarm** → many drones talking to {{each other}} and acting together.
- Counter-drone → jamming, {{GPS spoofing}} (feeding false location signals), lasers, guns.
- Civil uses → crop spraying, inspecting volcanoes and hazardous sites, collecting samples, mapping.

> [!TRAP] "All drones can hover / land vertically / run on battery" → all false.
