## Cell Basics {#cell-basics}

- Cell theory → Schleiden and Schwann; "cells come from cells" → Virchow.
- All cells have a plasma membrane and use {{DNA}} as genetic material.

| | Prokaryote | Eukaryote |
|---|---|---|
| Nucleus | {{None}} | Present |
| Organelles with membranes | Absent | Present |
| Ribosomes | Small (70S) | Larger (80S) |
| Examples | Bacteria, blue-green algae | Fungi, plants, animals |

| Organelle | Job |
|---|---|
| **Mitochondria** | Energy (ATP); own DNA |
| **Chloroplast** | Photosynthesis; own DNA |
| **Ribosome** | Makes protein |
| **Golgi** | Packs and ships |
| **Lysosome** | Digests waste |
| **Chromosome** | DNA + protein |

| | Plant cell | Animal cell |
|---|---|---|
| Cell wall | {{Cellulose}} | None |
| Chloroplast | Yes | No |
| Vacuole | One large | Small |
| Plasma membrane | Yes | Yes |

- Cell walls → plants cellulose · fungi {{chitin}} · bacteria peptidoglycan · Mycoplasma none.

## Microbes & Viruses {#microbes-viruses}

- **Virus** → not a cell; DNA **or** RNA inside a protein coat; multiplies only inside a {{living host cell}}.
- Viruses infect animals, plants, fungi and bacteria (bacteriophage); abundant in oceans; can change how host genes work.
- Bacteria and fungi grow on artificial media. Viruses !!cannot!!.
- **Adenovirus** → DNA. **Retrovirus** (HIV) → RNA.
- **Viroid** → bare RNA; plant disease. **Prion** → infectious protein.
- **Lichen** → {{fungus + alga}}; pioneer on bare rock; dies in polluted air.
- **Gucchi** → edible wild {{morel fungus}} of the Himalaya.
- **Pathogen** → disease-causing agent.

Nitrogen fixers, mycorrhiza, Azolla → [Biofertilisers](@prelims/environment/bioenergy-bio-inputs#biofertilisers)

## Plant Physiology {#plant-physiology}

- **Photosynthesis** → light energy stored as {{chemical energy}}; oxygen comes from splitting water.
- **Xylem** → water and minerals, up. **Phloem** → food, to wherever needed.
- **Girdling** (bark ring removed) → {{phloem cut}} → roots starve → tree dies.
- **Transpiration** → water loss through stomata; pulls water up.
- Plant diseases spread by wind, rain, dust, birds, insects.
- **Nepenthes** → traps insects for nitrogen but still photosynthesises.

Plant uses and adaptations → [Plants](@prelims/environment/plants#adaptations)

> [!UPPCS] Hormones: **auxin** growth, bending · **gibberellin** stem length · **cytokinin** cell division · **abscisic acid** closes stomata · **ethylene** {{ripens fruit}}.

## Classification & Evolution {#classification-evolution}

- Order → {{Kingdom → Phylum → Class → Order → Family → Genus → Species}}.
- Five kingdoms (Whittaker) → Monera, Protista, Fungi, Plantae, Animalia.
- **Egg-laying mammals** → platypus, echidna.
- Natural selection (Darwin) acts on inherited variation.
- **Homologous** organs → same origin, different use. **Analogous** → same use, different origin.
- **Denisovans** → extinct early humans, known from DNA (Siberia, Tibet).

Species and their habitats → [Species](@prelims/environment/species#behaviour)
