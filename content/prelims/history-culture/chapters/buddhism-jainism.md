## Shramana Setting {#shramana-setting}

- c. 6th–5th c. BCE, middle Ganga plain → Buddhism, Jainism, Ajivikas debate sacrifice, karma, liberation.

| | Buddhism | Jainism |
|---|---|---|
| Vedic authority, sacrifice | Rejected | Rejected |
| Self | {{No permanent self — anatta}} | {{Jiva affirmed}} |
| Path | Middle Path | Rigorous asceticism, ahimsa |
| Creator God | Not required | {{Cosmos eternal, uncreated}} |

> [!TRAP] Common ground = rejection of Vedic authority and ritual — !!not!! an identical attitude to austerity.

## Buddhist Doctrine {#buddhist-doctrine}

- **Four Noble Truths** → dukkha → craving → cessation → path.
- **Eightfold Path** → view, intention, speech, action, livelihood, effort, mindfulness, concentration.
- **Middle Path** → neither indulgence nor self-mortification.
- **Pratitya-samutpada** → dependent origination — !!not!! the same as momentariness.
- Three marks → {{anicca, dukkha, anatta}}.
- **Nirvana** → {{cessation of craving; release from rebirth}} — not heaven, not mere annihilation.
- Triratna → Buddha, Dhamma, Sangha.

| Term | Meaning |
|---|---|
| `Upasaka` | {{Lay follower}} |
| `Bhikkhu / Bhikkhuni` | Monk / nun |
| `Parivrajaka` | {{Wandering renunciant}} |
| `Shramana` | Renunciant striver — not a Vedic priest |

## Jain Doctrine {#jain-doctrine}

- Triratna → right faith, knowledge, conduct.
- Five vows → ahimsa, satya, asteya, {{brahmacharya}} (added by Mahavira to Parshva's four), aparigraha.
- **Jiva / ajiva** → living beings include {{earth-, water-, fire-, air- and plant-bodied}} forms.
- **Karma** → subtle matter binding the jiva → stop inflow ({{samvara}}), shed it ({{nirjara}}).
- {{**Anekantavada**}} → reality many-sided. · {{**Syadvada**}} → conditioned predication; `saptabhangi`.

> [!TRAP] Not "every inert object has a soul" — jiva and ajiva stay distinct.

## Jain Sects {#jain-sects}
