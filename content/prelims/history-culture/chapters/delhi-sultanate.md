## Dynasty Order {#dynasty-order}

> [!FLOW] Mamluk 1206–90 → Khalji 1290–1320 → Tughlaq 1320–1414 → Sayyid 1414–51 → Lodi 1451–1526

| Dynasty | Line |
|---|---|
| Mamluk | Aibak → Iltutmish → Razia → Nasiruddin Mahmud → Balban |
| Khalji | Jalaluddin → Alauddin |
| Tughlaq | Ghiyasuddin → Muhammad bin Tughlaq → Firuz Shah → later Tughlaqs |
| Sayyid | {{Khizr Khan}} — after Timur |
| Lodi | Bahlul → Sikandar → Ibrahim — defeated by Babur, 1526 |

- Balban → centralisation; frontier forts against Mongols.
- Muhammad bin Tughlaq's token currency → bad money drives out good → [Gresham's Law](@prelims/economy/economic-thinkers#greshams-law).
- Firuz Shah Tughlaq → Sanskrit manuscripts of Nagarkot translated → [Chronicles](@literature-travellers#persian-chronicles).

## Iqta {#iqta}

| Term | Meaning |
|---|---|
| **Iqta** | {{Revenue assignment for service}} — not ownership; not an Indian innovation |
| `Muqti` / `Iqtadar` | Holder → collects revenue, keeps troops and order |
| {{`Fawazil`}} | Surplus sent to the centre |
| {{`Khalisa`}} | Crown land — revenue straight to the treasury |
| `Inam` | Grant to religious / learned persons |
| `Kharaj` | Land tax |

- {{Iltutmish **regularised**}} the iqta — did not invent it.
- Strong sultans → transfers, non-hereditary tenure.

> [!TRAP] Iqta ≠ jagir ≠ khalisa → [Mughal jagir](@mughals#jagirdar-vs-zamindar).

## Alauddin Khalji {#alauddin-khalji}

- Large standing army on cash pay → {{`dagh`}} (horse branding) + {{`chehra`}} (descriptive roll).
- Market control → grain, cloth, horses, slaves, cattle → {{Shahna-i-Mandi, Diwan-i-Riyasat}}.
- Revenue → measurement, heavy demand, intermediaries curbed.

> [!FLOW] Gujarat 1299 → Ranthambore 1301 → Chittor 1303 → Deccan via Malik Kafur → Warangal 1310

## Mongols {#mongols}

| Ruler | Event |
|---|---|
| **Iltutmish**, 1221 | {{Chengiz Khan reached the Indus}} chasing Jalal al-Din; no confrontation |
| **Balban** | Frontier fortified; Prince Muhammad killed |
| **Jalaluddin Khalji**, 1292 | Incursion; settlers = "New Muslims" |
| **Alauddin Khalji** | Invasions c. 1297–1306; {{Delhi besieged, 1303}} |
| **Muhammad bin Tughlaq** | Tarmashirin's raid — no lasting NW loss |
| **Timur**, 1398 | Under {{Nasiruddin Mahmud Tughlaq}} |

> [!TRAP] Timur ≠ reign of Muhammad bin Tughlaq.
