## Bhakti — Safe Core {#bhakti-core}

- Personal devotion; roots in the Gita and Puranas → older than the "movement".
- Common tendencies → devotion over ritual, vernacular poetry, wider participation.

> [!TRAP] "All Bhakti saints rejected caste, idols and ritual" → false; positions differ by tradition. · Shankara (Advaita) is not a Bhakti founder.

Vedantic doctrines of Ramanuja, Madhva, Nimbarka, Vallabha → [Vedanta schools](@vedic-age-philosophy#vedanta-schools)

## Tamil Bhakti {#tamil-bhakti}

| Tradition | Anchor |
|---|---|
| **Alvars** | {{12}} Vaishnava saints; Nammalvar, Periyalvar, {{Andal}}; *Nalayira Divya Prabandham* — Nathamuni |
| **Nayanars** | {{63}} Shaiva saints; Appar, Sambandar, Sundarar, Karaikkal Ammaiyar; *Tevaram*; Manikkavachakar — *Tiruvachakam* |
| **Tamil Siddhas** | Yogic poet-mystics; monotheistic, anti-idolatry leaning; not one doctrine |

- c. 6th–9th c.; saints from many backgrounds; polemic against Jains and Buddhists.

## Lingayats {#lingayats}

- 12th c. Karnataka → {{Basavanna}}, Allama Prabhu, Akka Mahadevi.
- Personal `ishtalinga`; Kannada {{vachanas}}.
- Rejected caste hierarchy and ritual purity; {{questioned rebirth}}; burial of the dead.

## Sufi Vocabulary {#sufi-vocabulary}

| Term | Meaning |
|---|---|
| `Pir` / `Shaikh` / `Murshid` | Master |
| `Murid` | Disciple |
| `Khalifa` | Authorised successor |
| {{`Khanqah`}} | Hospice |
| {{`Silsila`}} | Order / lineage |
| `Zikr` | Remembrance of God |
| {{`Sama`}} | Musical assembly |
| `Dargah` · `Ziyarat` · `Urs` | Tomb-shrine · visit · death anniversary |
| `Wali` · `Baraka` | Saint · blessing |
| `Ba-shara` / `Be-shara` | Within / outside formal sharia norms |
| `Malfuzat` · `Maktubat` · `Tazkira` | Conversations · letters · saints' lives |

- Sufism grew gradually; in India from c. 11th–12th c.
- Practices → breath control, retreat, sama.

## Chishti Network {#chishti-network}

- Baba Farid → {{Nizamuddin Auliya}} → Nasiruddin Chiragh-i-Delhi.
- {{Amir Khusrau}} → disciple of Nizamuddin.
- {{*Fawaid-ul-Fuad*}} → Nizamuddin's conversations, compiled by {{Amir Hasan Sijzi}}.
- *Kashf al-Mahjub* → al-Hujwiri.

> [!UPPCS]
> - Centres → Burhanuddin Gharib — {{Daulatabad}} · Gesu Daraz — {{Gulbarga}}.
> - Pairs → Kabir — Ramananda · Amir Khusrau — Nizamuddin · {{Mardana}} — Guru Nanak · Surdas — Vallabha.
